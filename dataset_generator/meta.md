# Template Metadata
Each Template must have:
- description (e.g., "How many apples are there in the image?")
- answer (e.g., "3")
- topic (e.g., "Number")
- subtopic (e.g., "Types of number")
- source (e.g., "DynaMath")
- curriculum (e.g., "IGCSE")
- reasoning (e.g., "\begin{aligned}\text{Total surveyed} &= 201\...")

For topic and subtopic, please refer to syllabus of corresponding subject.
